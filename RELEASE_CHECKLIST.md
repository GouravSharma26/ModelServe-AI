# Release Checklist

## Before tagging
- [ ] All Fast Track acceptance criteria satisfied.
- [ ] Current branch and working tree inspected.
- [ ] No accidental secrets, datasets, database volumes, logs, or model binaries committed.
- [ ] Full tests and lint/type checks pass.
- [ ] Docker images build.
- [ ] Clean-start instructions verified.
- [ ] API and dashboard smoke test passed.
- [ ] Model evaluation results reproduced.
- [ ] Docs reviewed against implementation.
- [ ] Known limitations documented.
- [ ] Screenshots generated from the actual app.
- [ ] CI passes for the exact release commit.
- [ ] Public URL tested externally if listed.
